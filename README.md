# calendar

Java/Swing-приложение с календарём, годовым планировщиком, отметками и часами.

- `src/calendar` — календарь и планировщики;
- `src/clock` — компонент часов;
- `src/calendar/main/MainClass.java` — точка входа;
- `bin/calendar/icon` — ресурсы интерфейса;
- `app_build.sh` и `app_run.sh` — сборка и запуск.
